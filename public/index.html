Public Webhook Registration Guide (for production or ngrok tunnel)

  1. Expose local port 3000 using your preferred tunnel: npx ngrok http 3000
  2. Register the public tunnel URL with Mamo via API or dashboard: POST /manage_api/v1/webhooks with {"url": "https://<your-tunnel>.ngrok.app/webhooks/mamo", "enabled_events": ["charge.succeeded", "charge.failed", "subscription.succeeded", "subscription.failed"]}
  3. Mamo automatically verifies that the endpoint is reachable (HTTP 200) upon registration.
